# 🐉 HYdra v1.0.0 🐉 

Automated pipeline for dimensionallity reduction analysis

## Install
```bash
git clone https://github.com/matheusmeteoro/hydra
cd hydra
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Create your config.ini
To create your cfg, make a copy of "example.ini" and change the configuration for your use.

## You need a catalogue
The hydra.py need a catalogue in the configuration file, make one first.

## Run EXAMPLE
```bash
python3 hydra-stable-100.py --config example.ini
```

## To create plots
Enter in the folder "example" and see the data of "hydra100.csv"
